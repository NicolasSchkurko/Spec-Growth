# Scripts, flags and gate policy

**Scripts**: `gate-check.mjs` — checks + evidence. Flags: `--root DIR` · `--json` · `--scope <id>` (local focus: reds **from other changes** become warnings — report only) · `--run-tests` (runs `test_command` and records green evidence; the CI mode) · `--tests-command "CMD"` (`tests-substituted` mode: **no green**; forbidden in CI) · `--pre-archive <id>` (archive preconditions; tech briefs must be complete + signed off; squash-merge → `merged_as: <sha>`) · `--diff <base>` (protected files vs git diff) · `build-board.mjs` (BOARD.md + board.json, incl. the declared-deps Mermaid graph; badge conditioned on `gate_ok`) · `build-graph.mjs` (read-only: the same deps graph + the living specs and changes in flight — the raw material for `/spec-deps-graph`) · `risk-router.mjs` (read-only: `FAST` or `FULL` for `/spec-quick`, exit 0/10; flags `--kind`, `--targets`, `--id`, `--tech`, `--dep`, `--new-cap`, `--conflict`, `--decision`, `--max-roots N` — `SPEC_GROWTH_QUICK_MAX_ROOTS`, default 5) · `compact-archive.mjs --days=90 [--apply] [--force]` (yearly digest; requires a **clean, committed** folder before deleting; an invalid `--days` → error).

**Gate policy**: pre-commit (hook) → static `gate-check` (seconds). CI on PR → `gate-check --run-tests --diff <base>` + `openspec validate --all --strict`. Before archiving → `gate-check --pre-archive <id>` **OK**. Weekly → advisory semantic pass (`/spec-verify`).

**Code indexing (ladder)**: symbols → the **native LSP tool** (`lsp: true` + `OPENCODE_EXPERIMENTAL_LSP_TOOL=true`); literals → grep; orientation → `build-map.mjs [--root DIR]`, a ~2k-char map (folders → exported names; budget via `SPEC_GROWTH_MAP_CHARS`; regex-based, not a parser — nested or dynamic definitions may be missed; adapted from Ponytail's map, MIT) and the zero-dependency fallback for headless/CI. **Large repos only** (multi-language, deep call graphs): `codebase-memory` — when connected, prefer its graph queries for callers and impact.
